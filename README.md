Project Title
Simple C++ Console Calculator

Purpose
This program is a basic command-line calculator written in C++. It allows users to perform fundamental arithmetic operations (+, -, *, /) on two numbers. It also includes error handling for invalid operators and division by zero.

How to Run the Program
Save the Code: Save your C++ source code into a file named main.cpp.

Compile the Code: Open your terminal or command prompt and compile the program using a C++ compiler

Run the Executable: Execute the compiled program:
main.exe

Example Input/Output
Input:
Enter an operator (+, -, *, /): /
Enter first number: 8
Enter second number: 0
Output:
Error!!!!!!! divide by 0
